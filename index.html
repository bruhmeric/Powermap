    Connect your Supabase database

    Without a database the map runs in demo mode with simulated data stored in your browser. Connect a free Supabase project to go live — it takes about 3 minutes.

    1. Create a free project at supabase.com
    2. Open the SQL Editor and run the setup script
    3. Copy the Project URL and anon public key from Settings → API
    4. Paste them below and press Test connection

    The anon key is designed to be public — the table is protected by Row Level Security rules that only allow reading and creating reports (no edits, no deletes).

    About this map

    What is this?

    A free, community-powered map of electricity outages across all 25 districts of Sri Lanka. Anyone can report an outage or a restoration in a few taps — no account needed — and reports appear on the map for everyone in real time via WebSockets.

    How the numbers work

    Active outages counts ~1 km grid cells whose latest report is an outage, so an area that was reported and later restored isn't double-counted. Markers fade as reports age, and outage reports older than 24 hours are dimmed as possibly outdated.

    Privacy & data

    Reports are anonymous — no accounts and no IP logging. Your Supabase credentials (if configured) are stored only in your own browser. Submissions are rate-limited to one per 5 minutes per browser to discourage spam.
